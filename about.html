ABOUT

HJH

我在 GitHub 上以 dreamkeeperhu 记录项目。现在主要做三类东西：把网页里的重复操作做轻、把课程和学习流程整理成工具、把算法实验变成可复现的工程。

我喜欢清楚的界面、克制的动效和可以直接使用的原型。一个好项目不只要能跑，还应该让后来的人看得懂、改得动、继续接得上。

What I Build

项目先解决具体问题，再慢慢沉淀成可复用的工具和方法。

01

Userscripts

用轻量脚本补齐网页工作流里的缺口，例如 WeLearn 自动填充和北航课程辅助。

02

Optimization

围绕 Cloud-Edge-Device 任务调度做元启发式优化实验，关注可复现和参数可控。

03

Interface

把项目整理成能被访问、能被理解的界面，比如这个复刻 MiMo 气质的个人主页。

How I Work

从需求到页面，从脚本到实验，我更在意过程是否清楚、结果是否能被继续使用。

01 Start from friction 先找重复、低效、容易出错的地方，再用最小工具把它变顺。 → 02 Keep experiments reproducible 算法和工程实验尽量留下参数、数据入口和命令行说明。 → 03 Make work visible 把项目、链接和说明整理到一个入口，让作品不只停在仓库列表里。 →
